#🧮 Calculator App

A simple and interactive calculator web application built using HTML, CSS, and JavaScript.
This project was created to understand core frontend concepts such as layout design, styling, and basic interactivity.

#✨ Features

Clean and minimal calculator UI

Responsive button layout using CSS Grid

Smooth hover effects for better user experience

Supports basic arithmetic operations:

Addition (+)

Subtraction (−)

Multiplication (×)

Division (÷)

Clear (C) button to reset input

#🛠 Technologies Used

HTML – Structure of the calculator

CSS – Styling, layout, and animations

JavaScript – Logic and interactivity

#📚 What I Learned

Through this project, I learned:

How to structure a web page using HTML

How to use Flexbox and CSS Grid for layout

Styling buttons and displays to resemble a real calculator

Handling user interactions using JavaScript event listeners

Updating the DOM dynamically

Basic logical flow using conditions (if / else)

🌱 Future Improvements

Keyboard input support

Better error handling (without using eval)

Dark / Light mode toggle

Advanced operations (%, decimals)

📌 Project Purpose

This project was built as a learning exercise to strengthen frontend fundamentals and to better understand how HTML, CSS, and JavaScript work together in a real-world application.
